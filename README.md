# PASSING

Upload all extracted files and folders into the root of your GitHub repository. Keep assets/ and vendor/ intact.

In Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.

This package includes the latest slower clock, nearby object labels/highlights, and phone controls. No installation or build is needed.

For local play, serve the folder with a local web server. Opening index.html directly as a file will not load its JavaScript modules.
